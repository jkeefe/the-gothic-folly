Preview in a 3D Simulator

You don't need to wait until Burning Man to see your show. Design it, then watch it run on a live 3D model of the full cathedral — right in your browser.

The Gothic Folly show-builder package includes a downloadable 3D simulator and a 2D rose window preview. Use free, open-source tools — either xLights or TouchDesigner — to create your sequence, then watch it come alive in real time.

Every zone is represented: arches, spires, rose window, canopy, orbs. What you see in the simulator is what will run on the playa.

Anyone Can Build a Show

No experience with LED sequencing? No problem. We put together a complete beginner-friendly show-builder package — everything you need to start creating.

Download the package, open it in xLights (free, takes 5 minutes to set up), and start dragging effects onto the cathedral. The full step-by-step guide is waiting for you.
